# termynal.js: A lightweight and modern animated terminal window

A Pen created on CodePen.

Original URL: [https://codepen.io/ines/pen/MoaRYM](https://codepen.io/ines/pen/MoaRYM).

Termynal uses async and await, which is now supported pretty much across all major browsers. Termynal lets you write all input and output in plain HTML, and all styling in plain CSS. Non-JS users will still see the complete code, just no animation. It also comes with a flexible HTML API

Details: https://github.com/ines/termynal
