1. Token GitHub

Jak zrobić token (jednorazowo)
  1. Otwórz nowy fine-grained token.
  2. Nazwa np. CodePenFolders upload, ważność według uznania.
  3. Repository access → Only select repositories → .
  4. Permissions → Repository → Contents → Read and write. Nic więcej.
  5. Wygeneruj, skopiuj i wklej powyżej.

Token zostaje tylko w tej przeglądarce i jest wysyłany wyłącznie do api.github.com. Ma dostęp tylko do tego jednego repo. Nie zaznaczaj „Zapamiętaj” na cudzym komputerze.
